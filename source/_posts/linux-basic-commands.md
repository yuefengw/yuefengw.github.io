## Linux 常用基础命令

### 1\. 核心概念理解

| 词汇 | 全称 | 作用 | 通俗类比 |
| --- | --- | --- | --- |
| **Linux** | Kernel | 操作系统内核 | 大楼的地基和承重结构 |
| **Bash** | Shell | 命令行解释器/翻译官 | 传令兵（听你的命令告诉系统） |
| **Apt** | Advanced Package Tool | 软件包管理器 | 自动进货的采购员 |
| **Sudo** | SuperUser DO | 以管理员身份临时执行 | 尚方宝剑（见剑如见君，办完事归还） |
| **Su** | Switch User | 切换用户（默认切 Root） | 易容术（彻底变身为皇帝） |

* * *

### 2\. 基础命令 (Survival Kit)

#### 系统管理

-   `sudo shutdown now`: 立刻关机
-   `sudo reboot`: 立刻重启
-   `clear`: 清屏
-   `top`: 任务管理器（按 `q` 退出）

#### 导航 (我在哪？)

-   `pwd`: 显示当前路径
-   `ls`: 列出文件
    -   `ls -l`: 详细列表
    -   `ls -a`: 显示隐藏文件
-   `cd 目录名`: 进入目录
    -   `cd ..`: 返回上一级
    -   `cd ~`: 回家（用户主目录）

#### 文件操作 (增删改查)

-   `mkdir [名]`: 新建文件夹
-   `touch [名]`: 新建空文件
-   `cp [源] [目标]`: 复制 (Copy)
-   `mv [源] [目标]`: 移动/重命名 (Move)
-   `rm [名]`: 删除文件 (Remove)
    -   `rm -rf [目录]`: **\[高危\]** 强制删除文件夹及内部所有内容

#### 救命稻草

-   `man [命令]`: 查看说明书 (Manual)，按 `q` 退出。

* * *

### 3\. 文本编辑 (Nano)

适合新手的编辑器。

**操作流程：**

1.  **打开/新建**：`nano 文件名`
2.  **编辑**：直接像记事本一样打字
3.  **保存**：`Ctrl + O` -> `Enter` (确认文件名)
4.  **退出**：`Ctrl + X`

**查看文件内容（不编辑）：**

-   `cat 文件名`

* * *

### 4\. 权限管理 (Permissions)

#### 核心概念

-   **三类人**：`u` (主人), `g` (同组), `o` (其他人)
-   **三种动作**：`r` (读), `w` (写), `x` (执行)

#### 查看权限

使用 `ls -l` 查看，如 `-rw-r--r--`：

-   第 1 位：`-` 文件, `d` 文件夹
-   第 2-4 位 (`rw-`)：主人权限
-   第 5-7 位 (`r--`)：同组权限
-   第 8-10 位 (`r--`)：其他人权限

#### 修改权限 (chmod)

-   **加减法（推荐）**：
    -   `chmod +x run.sh` (给所有人加执行权限)
    -   `chmod o-r secret.txt` (把其他人的读取权限去掉)
-   **数字法** (`r=4, w=2, x=1`)：
    -   `chmod 777`: 所有人拥有所有权 (危险)
    -   `chmod 755`: 主人全权，别人只读/执行 (常用)

### 5\. 软件安装进阶

#### 自动档 (Apt)

-   安装：`sudo apt install 软件名`
-   卸载：`sudo apt remove 软件名`

#### 手动档 (.deb)

类似 Windows 的 .exe。

-   安装：`sudo dpkg -i 文件名.deb`
-   **修复依赖报错**：`sudo apt install -f`

#### 压缩包 (.tar.gz)

绿色软件或源码。

-   **解压口诀**：`tar -zxvf 压缩包名.tar.gz`
    -   `z`: Gzip
    -   `x`: eXtract (解压)
    -   `v`: Verbose (显示过程)
    -   `f`: File (后接文件名)
-   **压缩口诀**：`tar -czvf 打包名.tar.gz 源文件`

* * *

### 6\. 网络与远程

-   **查 IP**：`ip addr` (找 `inet` 后面的数字，通常是 192.168.x.x)
-   **测试连通**：`ping 目标IP`
    -   停止 Ping：按 `Ctrl + C`
-   **远程连接 (SSH)**：
    -   命令：`ssh 用户名@IP地址`
    -   例子：`ssh root@192.168.1.100`
    -   *注：输入密码时屏幕不显示任何字符，输完回车即可。*

* * *

### 7\. 效率与偷懒技巧

#### 重定向

-   `>`：覆盖写入 (清空原内容)
    -   `ip addr > ip.txt`
-   `>>`：追加写入 (保留原内容)
    -   `echo "log text" >> log.txt`

#### 管道 (|)

将前一个命令的输出传递给下一个命令。

-   **常用组合**：`命令 | grep "关键词"`
-   例子：`ls -l | grep "java"` (只查找包含 java 的文件)

#### 历史记录 (History)

-   `↑`：上箭头，翻看上一条命令。
-   `history`：查看所有历史命令列表。
-   **`Ctrl + R`**：**搜索历史命令** (输入关键词，系统自动匹配最近用过的)。
